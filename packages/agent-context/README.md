# Agent context

通用上下文编译与记忆合同。只依赖 `agent-core`，不导入剧本、小说、UI、数据库或模型 SDK；SQLite 端口位于 `agent-sqlite/contextStore.ts`。duilang 当前工作树的迁移依据、精确内容快照及适配说明在 `migration/manifest.json`。

- 编译实际 system、prompt、输出 schema、工具说明；不估算或限制单次输入 token，不设置应用输入预算。
- 所有传入来源与可应用 Skill 完整保留，不按输入长度拒绝请求或省略资料。模型服务的实际错误由现有调用链记录并返回。
- Skill 固定完整内容、版本、变量和实际配置；缺失变量报错。显式 `SKIP` 才允许整条不应用。
- 记忆分作者声明/模型派生与人工审核/自动收录两条属性；不替代正文事实、执行证据和授权。
- SQLite 按作者、作用域、分支隔离。来源变化/过期逐次重验，集合依赖指向实际有效查询结果，空结果也保存依赖。一次求值复用校验结果并设次数上限；派生记忆不能成为其自身来源查询的成员，循环写入整体回滚。
- 撤回/纠正使旧输入不能发送、消费、展示或采用。自动失效与真实撤权区分：历史提示词按冻结的精确来源检查访问权限。
- 来源事件登记派生重建队列；重建必须重新绑定来源并通过版本核对，不能复活作者删除/纠正的记录。
- `agent-sqlite/memoryWorkStore.ts` 持久化已提交来源的提取/重建任务、冻结请求、物理发送边界、回填与来源核验。每个作用域同时最多 64 个待处理任务；API 路由每 24 小时最多发送 20 次，SENT 后恢复为 UNKNOWN，绝不自动重发。错误返回保留原文且不写入记忆。

正式剧本宿主的 `ScriptMemoryScheduler` 自动发现已提交对话回复和工作稿版本，并在 runtime worker 节拍中冻结提取或失效重建任务。对话沿原已提交调用的 API 路由执行；没有固定 API 路由的作者工作稿使用外部回填渠道。受控 HTTP 路由可读取冻结任务与回填原请求；其模拟验收不代表艺术质量或供应商线上验证。跨作品授权仍以剧本领域的固定来源 grant 为准。原始冻结证据保存在本地 SQLite 供受控追溯；撤回通过公开投影与消费边界生效，不宣称 SQLite 字节级擦除。

验证：`npm run test:agent-foundation`、`npm run test:agent-script-http`。创作模型返回由 GPT-6 Sol 子 agent 生成；故障测试重放有来源记录的模拟 fixture，不能当作新一轮生成或艺术质量证明。
