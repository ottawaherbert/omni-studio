| 全剧总纲转委托时变成本集大纲 | 保留项目大纲归属，目标为“仅作品总纲”，停在 OUTLINE | 实际委托弹窗与目标合同断言 |
| 选中文字或指定多集批次转 Agent 时丢失边界 | 选区及批次使用明确的有限候选入口，生成后停止，采用才写入 | 候选入口与窄选区宿主测试 |
| 切阶段、切目标集仍携带旧范围，或把场景审阅变成整集审阅 | 不兼容阶段要求先明确选范围；换集清理旧故事／节点／场景；不支持的连续局部审阅明确拒绝 | 页面范围 helper、真实节点 REVIEW 命令 |
| 新建节点审阅带新增场数参数，被服务端拒绝 | 节点审阅只有既定节点读取范围，不带创建参数 | 内存宿主真实 GOAL_START |
| 空子段默认插到未归组尾声之后，破坏父段区间 | 在父段内按后续兄弟节点或父段末尾插入，保留原文及未归组场 | `script-design-domain-review` 原子插入回归 |
| 整片任务给已归组场景映射总纲时被拒绝；子段请求漏读父段目标 | 整单元允许映射对应单元／全片大纲；窄节点只映射已授权父子节点目标 | 实际候选构造、窄授权采用及冻结请求 |
| 节点插场或显式 before 的前文取错，模型传入 nodeId 可误导已有场大纲上下文 | 插入与上下文共用同一位置计算；已有场以已保存归属为准 | `script-required-writing-context` 四种实际冻结请求 |

| 部分批次返回没有独立的缺项提示 | 从冻结批次序号与实际返回计算未返回集数，采用前后均可查看 | 实际解析回归；不依赖模型自报“完成” |
| API 创建作品与后台任务争用写锁，保存的延迟事务在读后升级时立即失败 | 保存先取得写权再读取与核对版本，保留 CAS 及历史快照的原子性 | 两连接临时 WAL 库交错复现与真实 HTTP worker 用例 |

## 页面复核

使用既有隔离验收服务 `127.0.0.1:3014`，测试专属 SQLite 与禁用外部 provider 的宿主。新建样本“0930设计复核隔离样本”，ID 为 `script_4a87ecde-243a-4d39-ad06-659719453e54`。没有操作用户的 `3000` 页面。

- 连续剧全剧总纲快捷需求转委托，实际弹窗显示“仅作品总纲”与“故事大纲”停点，其他不兼容阶段不可直接选择。
- 样本第一集没有场景。从大纲页选择本集起三集，侧栏显示“委托本批规划”及明确停止说明。
- 修改本集大纲后点击委托：实际保存 v2→v3，任务基线为 v3，出现等待返回记录与测试回填入口，未生成假场景。
- 机械响应只返回第二集，实际采用 v3→v4；目录仅有两集，第一集作者文字与全剧总纲保留，第三集没有自动补建。
- 刷新后从历史重新打开已采用记录，仍可看到系统计算的“第 1、3 集未返回”，不依赖模型的总结文字。

这些是页面与协议证据，机械响应不是模型创作质量样本。上一轮宽窄屏四页、节点目标固定、保存期间再编辑、暂停后同步继续的记录仍保留在[浏览器验收](./audits/script-plan-implementation-2026-09-29/browser-check.md)。
