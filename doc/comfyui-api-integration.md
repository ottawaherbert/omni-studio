# ComfyUI 图片与视频服务

入口：设置 → ComfyUI 工作流 → ComfyUI 图片与视频服务。

1. 新增服务，填写名称、Base URL 和账号 API Key，保存后检查连接。当前服务地址为 `https://comfy.chuangyi.chat`，地址可编辑。连接检查只验证 `job:read`；生成、上传需要 `job:create`，下载需要 `asset:read`。
2. 载入 Qwen Image 2.1 文生图/参考重绘、YZ H3 文武戏参考、分镜首帧或四图宫格实验示例，或导入自己的「导出（API）」JSON。普通画布导出文件不能直接提交；作者原稿保留，使用转换后的执行图。
3. 声明工作流实际支持的生成方式、输入素材数量和声音输出，并配置参数映射。保存会创建对应的可选生成模型；点击“用于当前图片/视频生成”才更改对应任务路由。
4. 可展开“小型测试任务”，填写提示词并提交一次测试。图生图、图生视频及多素材参考需要提供配置数量的全部素材；系统不会静默忽略参考。
5. 图片、视频进入既有生成入口，任务完成后结果先下载到系统媒体目录，再交给既有素材或视频候选流程。设置页的任务列表也保留每个输出文件的本地访问入口。

## 工作流与映射

一个生成模型绑定一个工作流，工作流明确绑定一个服务。系统不会默认使用第一个工作流，也不会根据模型名称猜测参考素材能力。

映射项包含 `systemParam`、`nodeId`、`nodeInput`。可配置 `prompt`、`width`、`height`、`aspectRatio`、`duration`、`seed`，以及 `image:0`、`video:0`、`audio:0` 等从零编号的素材输入。参考素材先上传到当前账号，再把返回的完整文件名写进对应输入。

`valueMap` 可转换供应商节点的枚举拼写。例如视频示例把 `16:9` 转为 `16:9 (Widescreen)`。示例仅提供接入文档确认过的枚举值；其他画幅需要按实际节点补充。节点 ID 只存在于可编辑示例和配置，不固定在通用执行器中。

随附示例分别声明自己的实际能力：纯文本、Qwen 单图重绘、H3 单首帧、三图参考、四图宫格规划。输入数量对应实际加载节点数量，多参考输入顺序以映射编号为准。只有明确声明 `multiShot` 的视频工作流才允许多个镜头共用一次生成，旧配置默认不开放；图片工作流不能声明该能力。视频和音频参考只有在配置完整上传映射后才可使用。

当前 H3 服务单次不得超过 14 秒，内置预设同时校验请求上限并把对齐帧数限制到 328 帧，避免 14 秒向上对齐到 14.375 秒。普通分镜首帧提供作者的 10/6 标准文戏档和 8/4 快速档；保留融合加速 LoRA、SelfLift 和 LMS 链路。四图宫格仍为实验配置，接线有效不代表正式画面合格，须逐段检查。详见 [YZ 参数与本集实测](comfyui-yz-h3-production.md)。

## 队列、取消与恢复

同一服务下的图片、视频共同使用本系统的在途任务预算，默认 2 个；本次服务按用户确认配置为共享 7 路。它是本系统的提交限制，不代表独占 GPU；服务端仍按所有账号共享的动态容量排队。不要把服务端当前 GPU 数量分别填成图片、视频各自的独占并发。

- HTTP 429 根据 Retry-After 和退避时间重试；已获得 prompt_id 的任务持续查询原任务。
- 提交发生网络错误、5xx 或无法解析成功响应时标记“提交结果待核对”，停止自动重发。可查看账号近期任务，填写 prompt_id；后端核对上游完整工作流与已保存请求相同后才允许关联。
- 等待上限只结束页面等待，不取消上游任务。后端任务记录和查询仍保留，可以恢复下载。
- “取消任务”向上游发送取消请求，最终状态以之后的任务查询为准。已知未提交的本地排队任务可以直接取消。
- 服务器重启后恢复查询已知 prompt_id；在提交途中中断且没有上游编号的记录进入待核对状态。
- 文件下载失败时保留上游任务和已有下载，不重新生成。系统识别 images、gifs、videos、audio，支持 gifs 数组中的 MP4。

## 凭证与素材

ComfyUI Key 保存在现有后端配置库中，配置 API 向浏览器返回保留标记，编辑时用密码框输入。空白占位表示已存凭证，无需再次填写。上游地址禁止携带 URL 用户名、密码、查询和片段；带凭证请求不跟随重定向。

公开参考素材通过现有公开地址检查下载，不携带 ComfyUI Key；也支持系统 `/media/` 素材与文件上传。输出下载携带账号 Key，保留实际 filename、subfolder、type 三元组，随后写入 `OMNI_Workspace/Media_Assets/comfyui/<本地任务编号>/`。浏览器使用本地 `/media/` 地址，无需拿上游凭证打开结果。

## 验证

`node --import tsx --test tests/comfyui-gateway.test.ts` 使用模拟服务和隔离数据库，覆盖参数与能力校验、认证、上传、图像与视音频回存、共享预算、429、提交不确定、恢复、取消、节点错误和凭证遮罩。真实联调报告另行记录实际 prompt_id、输出路径、文件大小及 ffprobe 结果，不记录 Key。
