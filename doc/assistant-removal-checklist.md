# 内置助手退出清单

日期：2026-10-24。清理前提交：`3c1366d0`。本清单记录实施，不替代 `design.md` 的当前操作合同。

目标：外部 Agent 与人使用同一套作品编辑、任务、生成、校验和采用工具；移除内置聊天助手及自主规划循环。保留作品、媒体、历史候选与已有数据，不启动真实生成。

- [x] 全站助手：移除导航入口、面板、事件、客户端、能力注册、规划器、专用运行时、路由及仓储代码；不再启动后台筹备循环。
- [x] 写作助手：移除聊天和自主规划界面、会话与自动执行服务、专用提示词及失去消费者的实现；保留正式编辑、保存、导入导出。
- [x] 业务工具：把专项写作任务、外部回填、候选查看/采用、历史查看从助手中迁出；页面入口明确目标、结果和状态，不换名保留聊天助手。
- [x] 规则收敛：修复机械连续性检查；外部 Agent 能力说明按实际任务区分工具与批量流程；统一模板来源、默认版本与自定义覆盖；H3 采用实时能力而非示例槽位。
- [x] 文档与残留：更新系统设计、指南、README、H3 说明；移除被替代的助手设计/提示词/测试/启动脚本与无消费者代码，修复引用。历史数据不清空。
- [x] 验收：类型和构建；退役路由/后台循环检查；写作任务回填/采用/冲突与导入导出；生成能力/暂停/H3 回归；桌面入口操作；更新交接与逐项证据。

保留边界：外部 Operator 接口、确定性领域校验、按用户要求执行的单次模型工具、生成工作台、共享队列、固定计划、来源与版本、授权及暂停。内部实现名称带 Agent 不构成删除依据；只有仍被上述业务依赖的共享能力可以保留，不能保留隐藏的自主聊天执行链。

验收结果（含独立审查后的修复）：

- 全站与写作自主执行入口、专用包、worker、路由和聊天模板已移除。旧 API 返回 410，不再启动对应后台循环；业务名中的 Agent 单次工具与外部 Operator 合同继续保留。
- 写作保留项目编辑、任务、外部回填、候选及正式采用。历史助手任务只读，旧草稿/候选/对话/筹备成果按固定表白名单分页导出；没有迁移覆盖或删除真实数据库。
- 提取通用文本传输与内容哈希，保留供应商配置、固定路由、错误分类与凭证保护。清理只属于旧执行器的测试，保留混合文件中的领域测试并增加退役边界回归。
- 默认模板增加基线指纹；识别出的旧默认随版本更新，自定义与无法判定来源的旧文本保留。缓存中的聊天模板被过滤。制片模板追踪不再把与内置相同的缓存内容误记为自定义。
- 桌面 1440×1000 隔离验收：创建作品、打开专项任务、准备提示词、回填固定 JSON、查看候选、采用，字段正确更新。未调用真实模型。截图与日志：`artifacts/assistant-removal-2026-10-24/`。
- 代码检查与实际 HTTP 检查分别记录于 handoff 最新检查点。没有执行真实图像、视频、音频生成；H3 扩展输入的真实服务/画面验收仍沿用上一检查点的待验收状态。

- 独立初审发现的 8 项回归和 1 项既有商业规则冲突已全部修复，具体反例和逐项复验见 [独立审查报告](audits/assistant-removal-independent-review-2026-10-24.md)。写作范围由服务端执行，工具入口从作品菜单恢复，模板默认选择可持久保存；没有把助手改名放回系统。
- 后续回归运行 `npm run test:assistant-retirement`（含真实持久化迁移、写作采用范围、隔离浏览器服务 HTTP、共享生成队列与非商业长篇），并结合 `test:script` / `test:module-readiness`。固定任务与历史只读导出是保留业务边界；任何新增聊天规划或自主执行必须另行设计，不能借历史数据恢复。
