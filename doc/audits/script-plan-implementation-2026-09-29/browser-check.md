- 作者完成场景时，旧分场变更检测把 generation 状态也当作规划变化，产生误提示。已从规划比较中排除此状态，加入结构目录与本故事大纲的实际变更检查；20 项最终页面／流程回归通过。这项最后的后端提示修正以自动测试验证，未冒称已重启隔离服务再跑一次浏览器。
- 最后复核修正了“调整委托时切换两个同类节点仍沿用旧目标”，以及“从节点写作切换审阅时变成整单元”的问题。稳定身份恢复和范围比较已有针对回归；没有把 helper 回归称作浏览器操作。
- 本轮没有在浏览器跑完完整长片、连续两集、两个独立故事及续篇、两类中国短剧的全量真实模型创作。完整 BODY 与节点 BODY 的多次追加和最终检查由真实宿主机械协议测试覆盖，详见实施报告。
- 本轮没有浏览器重跑全部冲突组合、结构成员变动后的每一种确认路径、分页超过 80 场的交互；相关服务端范围／恢复／分页测试已通过。未进行作者艺术质量验收。
