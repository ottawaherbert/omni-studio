# 示例委托：《末班渡口》

本例是新写的虚构作品，仅用于演示外部创作交付与离线检查。

- projectId：project_last_ferry；首次 deliveryId：delivery_last_ferry_001。
- 作品形式：中文互动微短片，单部，16:9，AI 视频制作，成年观众。
- 玩家角色：林岚，刚办完父亲后事，正在赶离岛的末班船。
- 固定事实：她在父亲包里发现失物柜的铜钥匙；新看守沈叔不知道她有钥匙；交回并核对物品会错过末班船；柜内证据不能立刻证明父亲全部行为的原因。
- 目标体验：保护亲人秘密与留下可追查记录的取舍。两种选择有可理解的得失，不以道德判词收尾。
- 限制：两个有对白的人物，一个主要渡口环境；沈叔腕部扭伤；不增加超自然解释或戏剧化审判。
- 方法：仅选“选择有可见代价”，不强制套用固定幕结构。
- 规模：一处选择、两个结局、一次可共用画面的汇合。单次内容目标 105 秒，粗估范围 90–120 秒；独立视频预算 180 秒；最长无选择内容目标 80 秒。
- 时长不包含玩家等待、片头和片尾。外部不生成视频，最终时长在系统内制作后测量。
- 交付：完整设定、六场全部正文、可运行条件图、制作量计划和设计说明。父亲动机可以保留未解部分，这属于有意的开放性，不是缺交正文。

该项目明确要求小规模。新项目可有更多章节、选项和变量，不以这个样例的数量为默认上限。
